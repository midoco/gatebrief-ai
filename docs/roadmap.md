- Repository, license, README, secrets hygiene.
- FastAPI health endpoint.
- Flutter demo shell.

- Connect Token Factory with NEBIUS_API_KEY.
- Discover available Nemotron model.
- Return structured readiness summary.

- Expand deterministic rule engine.
- Add 20+ synthetic flight scenarios.

- Conditional Tavily calls.
- Domain/source controls.

## M4 - Document intelligence
- Upload PDFs/images.
- Extract document types and fields.
- Compare extracted data to canonical flight record.

## M5 - Human-in-the-loop product
- Findings timeline.
- Reviewer actions and notes.
- Audit trail.
- Arabic/English UI if time allows.

## M6 - Submission polish
- Evaluation report.
- Architecture diagram.
- Public deployment.
- 2:30 demo video.
- Final Devpost submission.
